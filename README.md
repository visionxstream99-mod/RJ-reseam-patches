## Install

1. Install [Reseam Manager](https://reseam.app).
2. Open **[Add RJ Reseam Patches to Reseam](https://reseam.app/add/?url=https%3A%2F%2Fgithub.com%2Fvisionxstream99-mod%2FRJ-reseam-patches)**.
3. Select a patch that matches your app version, review its options, and follow the manager's prompts.

If Reseam warns about an app-version mismatch, stop and review the patch notes rather than forcing it.

## Compatibility notes

Patch compatibility depends on the exact app version. A patch should only be called target-checked after a dry run or application against the stated original APK, and runtime-tested only after it has been launched and tested on a device.

The source tree and latest release bundle may differ. Check the actual patch manifest to confirm what is downloadable. Pinterest and HyperLock are version-specific; Hotstar has no pinned target version yet.
